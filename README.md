# RedCrownedCrane_YRD_multiscale_analysis

Final manuscript-oriented R workflow for:

"Emerging breeding use of the Yellow River Delta by Red-crowned Cranes in a changing coastal wetland mosaic"

## Workflow

1. Multiscale Sentinel-2 environmental comparison
2. CLCD land-cover composition and trajectory analysis (2017-2023)
3. Exploratory random forest assessment
4. Figure generation

## Data protection

Exact nest coordinates are excluded because breeding locations of Red-crowned Cranes are sensitive conservation information.

This repository is designed for reproducible analysis using de-identified processed datasets.
